# YUKTI Engineering & Projects website

Standalone source code for the YUKTI Engineering & Projects website.

## Local development

1. Open a terminal in `app`.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address shown in the terminal.

## Production check

From `app`, run:

```sh
npm run build
```

## Uploading to GitHub

Upload the complete `YUKTI-Website-Source` folder, including `.github` and `app`. The website source, assets, dependency lock file, and build workflow are all included.
